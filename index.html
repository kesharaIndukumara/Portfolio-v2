Full-Stack Developer Intern · Helixz Solutions

Pnyx is a survey platform covering survey delivery, respondent flows and admin tooling. I work on its frontend, where the team is migrating the product from a React + Vite codebase to Next.js (App Router) to gain file-based routing, server rendering and built-in API routes.

Next.js 15 TypeScript Redux Toolkit redux-saga NextAuth Ant Design MUI Radix UI Tailwind CSS styled-components ApexCharts React Hook Form Zod pnpm

What I do on the project

  • Migrate feature modules (authentication, respondent flows and shared UI) from the React + Vite codebase to the Next.js App Router, using the server / client component pattern.
  • Build and maintain production features in TypeScript within a modular, feature-based architecture.
  • Manage application state with Redux Toolkit and redux-saga; handle auth and OAuth via NextAuth.
  • Implement interfaces with Ant Design, MUI and Radix, styled with Tailwind CSS and styled-components; wire up charts, forms and Zod validation.

  • Collaborate in an agile team and translate client requirements into shipped functionality.
